# niehewang.github.io

Static GitHub Pages site for Hewang Nie.

## Pages

- `index.html` - bilingual academic homepage with SEO metadata, theme/language switching, publication search, year/level filters, citation copy, and responsive navigation.
- `ccf-2026.html` - CCF 2026 journal/conference and 2025 Chinese T-tier journal lookup tool with smart search, filters, table/card views, shareable query URLs, and copy actions.
- `research-workbench.html` - local-only personal research workbench for todos, submissions, reviews, students, projects, time logs, links, templates, backups, and lightweight local locking.
- `404.html` - GitHub Pages fallback page.

## Assets

- `assets/site.css` - shared homepage visual system and responsive styles.
- `assets/site.js` - homepage interactions: theme, language switch, publication tools, copy actions, scroll tools, and keyboard shortcuts.
- `assets/favicon.svg` - site icon.
- `photo.jpg` - homepage portrait.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server. No build step or package install is required.

## Privacy Note

The research workbench stores data in the current browser's `localStorage`. Do not put sensitive private data in source files before publishing to GitHub Pages.
