Research OS v6 — 使用说明
===========================

1. 把本目录中的全部文件覆盖上传到你的 niehewang.github.io GitHub 仓库。
2. 等 GitHub Pages 更新后访问：
   https://niehewang.github.io/research-workbench.html
3. 输入你已经设置的工作区密码。
4. 点击右上角“连接 Google Drive”，完成 Google 官方授权。
5. 之后建议按这个顺序使用：
   - 今日科研：刷新 Drive 与项目状态
   - 项目监视：自动发现 / 添加长期研究项目
   - 论文雷达：模型安全、具身抓取、跨域灵感分 Profile 扫描
   - 实验体检：从 seed / retry / status / result / log 判断实验目录健康度
   - 阅读笔记：从 Radar 一键生成 Markdown 阅读卡
   - Drive 整理：扫描重复、临时命名、根目录散落、缺阅读笔记、敏感材料

Drive 整理中心不会自动删除任何文件。
移动和重命名只有在你勾选并确认后才会执行。

Google OAuth Client ID 已预置，因此通常不需要重新配置 Google Cloud。
