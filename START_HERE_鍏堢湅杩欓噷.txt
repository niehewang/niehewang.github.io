Research Radar v5 使用方法：

1. 把这个文件夹里的全部内容覆盖上传到你的 GitHub Pages 仓库。
2. 打开：https://niehewang.github.io/research-workbench.html
3. 页面会先出现个人访问门禁；输入你设置的访问密码后进入。
4. Google OAuth Client ID 已预置，无需再次粘贴。点击“连接 Google Drive”即可弹出 Google 官方授权窗口。
5. 点击“扫描最近一年”开始论文发现。新版来源包括：
   - IEEE Transactions
   - ACM Transactions
   - CCF A 类期刊 / 会议
   - arXiv
6. Balanced 模式默认会同时搜索：模型版权/水印/归因 + ML/LLM/生成模型安全 + 隐私/后门/窃取/取证/可信 AI + 密码学/统计/信息论/异常检测/表示学习等跨域方法。
7. Drive 连接后会自动与 paper 文件夹去重；勾选开放 PDF 可一键归档。

重要说明：
- 访问密码是 GitHub Pages 上的“前端门禁”，用于防止普通访客随意进入，不等同于服务器端身份认证。
- Google Drive Access Token 只存在当前页面内存，不写入 GitHub，也不长期保存在浏览器。
- 论文搜索无需 Cloudflare Worker、SerpAPI 或其他后端。
